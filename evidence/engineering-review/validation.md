# Android 设备验证合同

状态：工程审阅候选，尚未实施／运行。原独立 [A01–A16](../figma-android-design/review/inputs/expected.json)不改，本页只固定正常操作驱动、断言、超时和证据。两设备各 16 项，精确 32 对 `(device, case)`；内部子断言不额外凑测试数。

## 共同前提与独立断言

固定源 SHA、APK SHA 与内容树，设备匹配独立预期的 AVD、镜像、API、ABI、页大小、分辨率和密度。启动时记录 font_scale、方向与旋转设置，结束在 `finally`／取消清理中恢复；清理未知仍为失败。ADB 使用本次专用 5038，AVD 使用 5580／5582；先检查端口与设备归属，不能抢占或关闭其他进程。

操作使用真实 `adb input tap/keyevent` 和正常启动／force-stop。冷启动记录 PID 与进程启动身份；Home 往返必须证明同进程，真冷启动必须证明新进程。截图、XML、私有只读观察均保存原始结果及命令退出码；只读观察不得给主机预先生成 PASS。每次等待最多到规定时限，不能无限重试或用固定睡眠掩盖未绘制。

字号每次先从系统设置读取实际档位，再核对实际 Paint 字号、截图和控件安全区。审阅中提出的线性视觉字号解释取得确认后才采用；仍须匹配原参考及无裁切义务，不把设置成功当渲染成功。

## 视觉和资源判定

- 七状态在每台每档各保存截图；两种 best=0 弹窗变体另外留存。已有 16 张参考是家族参考，其他变体只采用 D 明确允许的文案／启用差异。
- 颜色、几何、文案及换行按 D；非文字边缘误差至多 1 个物理像素，文字基线至多 2 dp。明确受检控件及参考坐标，保留差值；系统栏只按实际 Insets 对齐，不拉伸全幅参考。
- 真实文字可见范围、按钮重叠及可访问范围同时检查；XML／View 属性和截图共同证明。不能仅凭资产哈希、公式或观察日志宣布视觉通过，最终仍有人审。
- PNG／tokens D 摘要→APK 实际条目→运行已加载摘要与节点关系闭合；位图取样差异只沿原允许项，缺资产、参考图代替原生界面均失败。

## 有限超时与恢复

| 项目 | 上限 |
| --- | --- |
| 原生构建 | 900 秒 |
| 每台 AVD 启动 | 240 秒 |
| 每次 ADB／观察等待 | 20 秒／10 秒 |
| A01–A11、A13 单例 | 90 秒 |
| A12、A14、A15、A16 单例 | 240 秒 |
| 每台完整 suite | 1800 秒，包含失败清理前的测试动作 |
| 最终设置恢复／进程清理 | 120 秒 |
| 后续真实 CI Job | 90 分钟 |

这些是上限，不是固定等待。两设备可顺序执行；独立 ADB、SDK 与有限端口归属不变。失败保存证据后定位，只有实现修正、环境恢复或明确新诊断理由才定向重跑；取消／宿主强杀的清理未知不能算成功。

后续平台入口拒绝缺报告、零项、重复／缺少 device-case、跳过、取消、超时、源／APK／设备身份不符及清理失败。真实 CI 按原合同至少五轮：正常、平台编译失败、恢复、共同输入缺失、恢复；输入失败时原生步骤必须未运行，两次恢复重新实际跑 32 项。每轮保存托管 Job、required check、PR 状态和完整产物，不以本地仿真替代。

## 证据留存

实际 Change 保存唯一 Tasks、当前请求／Review、bindings、propose/start/resume 和 CI 前后 current 结果；运行记录绑定 source SHA、规则／工具、APK、D/A、设备及原独立预期摘要。证据包括 RED/GREEN、构建日志、32 项原始断言、截图/XML/观察、设置恢复、全部失败、真实 CI 日志／产物与人审原话。

工具制作源不再可用时仍能从批准 bundle／远程恢复相同包；消费者源码与必要产物也须独立恢复。只有真实运行人审与获授权归档完成后，才记录 Android 及相应 Figma 消费链通过。Unity 保持单独的未完成义务。

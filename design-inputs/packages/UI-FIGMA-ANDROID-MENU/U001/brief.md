## 需求与范围

复用本轮已经验证的菜单业务流程，改用实际 Figma 制作／读取及独立 Android 原生 App 消费。新设计来源及平台另建新 D/A，不复用 Cocos 批准。

- 冷启动 best=128、无会话，Continue 禁用；New game 建立一次会话。
- 会话页只是静态 2×2 预览，Menu 返回后 Continue 恢复同一次会话；不实现完整棋盘玩法。
- Reset best score 打开确认框；Cancel 保持全部状态，Reset 只把 best 置为 0，保留既有会话。
- 零分、无会话时仍可 New game，不能 Continue；零分、有会话时可 Continue。
- Back 在弹窗取消、会话返回菜单、菜单退出前台；存活进程 Home/返回保留当前状态，进程结束后的新启动回初态。
- 不增加存档、网络、账号、广告、音频、商业或物理真机要求；没有文本输入，键盘不适用。

工程起点：已经实际构建／安装的隔离 Android 空白探针，Java 17、AGP 8.13.2、Gradle 8.13、compile/target SDK 36。它只证明工具链可用，不能计入设计消费。正式工程在新 D/A 和原工程 Review／Apply 后建立，采用唯一 OpenSpec Change Tasks。

## 平台与尺寸

- Android 原生界面；竖屏、英文、浅色。设计单位 dp，文字 sp，Roboto／平台对应无衬线；不嵌入字体文件。
- 固定两台已有专用 API 37 ARM64／16 KB 模拟器：720×1280、density=320；1080×2400、density=420。参考 Figma 外框分别为 360×640 和 411.428571×914.285714。
- 系统栏由系统绘制；内容按实际 WindowInsets 留安全区。参考的系统栏空间只示意边界，系统图标不作产品资源。
- 字号 1.0／1.3 都需可读且不裁切；大字号允许按预先写明的紧凑间距、内容高度和换行规则适配，禁止统一缩小整页绕过字号。
- 触控区域至少 48 dp；所有必需动作在小屏上可见。原生按钮及对话框须有可访问名称、禁用及模态语义。
